# Automated-Expense-Tracker-Budget-Manager
Automated Expense Tracker &amp; Budget Manager is a solid choice. It cleanly aligns with core Java Object-Oriented Programming (OOP) principles, data management, custom error handling, and file persistence.
Problem Statement

Personal financial tracking is often tedious and inconsistent when managed manually, leading to overspending and a lack of clear budget insights. Traditional spreadsheets lack real-time input validation, automated category limits, and structured alerts. This application provides a lightweight, modular Java-based system to record transactions, monitor category budgets, and analyze spending habits efficiently. 


Scope of Project-
Multi-account & user profile tracking (Cash, Bank, Credit Card).  
Expense/Income entry logger with category tagging (CRUD operations). 
Automated budget threshold monitoring and alert generation. 
Data persistence via JSON file handling or SQLite.  
Financial summary reporting and CSV data export.


Target Users
Individual Users / Students: Managing personal daily allowances and expenses.  
Freelancers: Tracking diverse income streams and basic business expenses.


High-Level Features
Transaction Management: Add, update, view, and delete income and expense logs. 
Budget Allocator: Set monthly spending limits per category (e.g., Food, Utilities, Entertainment). 
Analytics Engine: Compute totals, average spending rates, and budget consumption percentages.  
Data Persistence & Export: Automatically save session states and export summary logs to CSV.
